## The roast

One line, 130 characters, roasting my own agent — the tool calls that go
nowhere, the confident wrong answers, and the eager request for a rating:

> My agent made six tool calls to plan this roast, got every fact wrong with total confidence, then asked me to rate its brilliance.

## How it works

`main.py` (standard library only) writes exactly that one line to
`/output/entry.txt` — no trailing newline, no extra text. Run it with:

```sh
python3 main.py
```
